# Wild Almanac

A NeoForge mod for Minecraft 26.3 that adds seasons and wild animals that hunt, nest, burrow and raise their young.

This mod is in early development.

## Building

1. Open this folder in IntelliJ IDEA and let Gradle finish loading.
2. Run the `runClient` task (Gradle panel → neoforge → runs) to start the game with the mod.
3. Run `gradlew build` to make the mod file. It ends up in `build/libs/`.
